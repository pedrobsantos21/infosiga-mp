Matrix profile dos sinistros de trânsito — SP

O matrix profile mede, para cada subsequência de tamanho m, a distância até a subsequência mais parecida no resto da série. Valores altos indicam comportamento atípico; o maior deles é o discord. Valores baixos indicam padrões recorrentes; o menor é o motif. Fonte: Infosiga SP (dados abertos). Baixar dados (CSV).
